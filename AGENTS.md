# Instructions for coding agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) and follow it as written. It holds
the conventions for this repository: how to make a change (an issue for
every change, a branch per issue, commits at each logical step, the
maintainer merges), the style, how to run the tests and build the
documentation, how dependency bounds are kept, and what is expected when AI
is used ("Use of AI").

Where CONTRIBUTING.md is silent, ask the maintainer rather than guess. Do
not copy its rules into this file: there is one source of truth.
